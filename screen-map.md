# VASUDHA implementation checklist (reference: SIH_PS2_PDF.pdf)

| PDF page | VASUDHA screen | Key reference elements |
|---:|---|---|
| 1 | Home / landing | Waterscope hero, landscape map visual, layer chips, header and CTA; rebrand to VASUDHA |
| 2 | Login | Landscape background, welcome/login panel, User and Organization role selection |
| 3 | Watershed Explorer | Tool rail, Land Use map, search/map controls, legend and map information |
| 4 | Drainage Map | Drainage layer map, stream legend and map information |
| 5 | Vegetation Map | Vegetation layer map, vegetation legend and map information |
| 6 | Watershed Intervention Map | Intervention markers, category/status legend and map information |
| 7 | Intervention quick detail | Centered before/after detail modal over the intervention map |
| 8 | Afforestation detail | Photo comparison, key parameters, project impact, right-side site information |
| 9 | Contour Trenching detail | Map/photo, project rationale, key parameters and right-side site information |
| 10 | Geotagged Photos | Organization upload drop area, search, photo gallery and metadata |
| 11 | Analytics dashboard | Analysis tool rail, watershed selection, indicators, change map, trends and summary cards |
| 12 | Land Use Analysis | Land use map, class legend, charts, area details and key insights |
| 13 | Drainage Analysis | Drainage map, hierarchy, density, stream statistics and insights |
| 14 | Vegetation Analysis | Vegetation map, class legend, vegetation charts and insights |
| 15 | Soil Moisture Analysis | Moisture map, explicit sample-data context, chart and moisture statistics |
| 16 | Water Bodies Analysis | Water map, water body stats, categories, change and insights |
| 17 | Land Degradation Analysis | Degradation map, severity categories, change chart and insights |
| 18 | Watershed Intervention Analysis | Intervention map, category summary, selected-site details and insights |
| 19 | District Watershed Report | Report header, indicators, district map, charts, report details and export actions |

All analysis values and GIS layers included with this build are labeled DEMO. They are structured separately from UI so verified GIS datasets can replace them.
